Install guide

Get Nocturn running on your machine

Pick your platform. Each path ends with the same gateway on your own computer, the control panel in a window or a browser tab, and an agent that asks before it acts.

Windows

Download Nocturn-Setup.exe and run it. The installer puts Nocturn in your user folder, adds a Start menu entry and a desktop shortcut, and needs no admin rights.

!

Windows will show a blue “Windows protected your PC” screen. The installer is not yet signed with a paid code-signing certificate, so SmartScreen does not know it. Click More info, then Run anyway. The file you downloaded from this site is the same one GitHub Actions built from the public source; you can compare its SHA-256 with the one on the release page.

Prefer the terminal? In PowerShell:

$ npm.cmd install -g @morpheapp/nocturn
$ nocturn.cmd onboard

If PowerShell refuses with “running scripts is disabled”, use the .cmd forms above, or allow local scripts once with Set-ExecutionPolicy -Scope CurrentUser RemoteSigned.

macOS

Download Nocturn.dmg, open it, and drag Nocturn into Applications. It works on Apple silicon and Intel.

!

macOS will say the app “is damaged” or “cannot be opened because the developer cannot be verified.” The app is not yet notarized with an Apple Developer ID. Open Terminal and remove the quarantine flag once:

$ xattr -dr com.apple.quarantine /Applications/Nocturn.app

Then open it normally. Or install from the terminal, which needs no workaround:

$ npm install -g @morpheapp/nocturn
$ nocturn onboard

Linux

Use npm with Node 22 or newer. To keep the gateway running after you log out, install it as a user service.

$ npm install -g @morpheapp/nocturn
$ nocturn onboard
$ nocturn gateway install
$ loginctl enable-linger $USER

Android

The Android app is a client. It does not run the agent; it connects to a gateway you run on a computer or server. Download Nocturn.apk on the phone and open it.

!

Android will ask you to allow installs from this source because the app is not on the Play Store. Allow it for your browser, install, and you can turn the permission off again afterwards.

On the first screen, enter the gateway address and the private token from nocturn dashboard. Both devices must share a private network such as Tailscale, and the gateway must be started with NOCTURN_HOST=0.0.0.0 and NOCTURN_TRUSTED_HOSTS=<its address on that network>. Never expose the gateway to the open internet.

Web app, any device

Open http://127.0.0.1:18790/panel.html on the machine that runs the gateway, or through an SSH tunnel from another one, and choose Install app in the browser menu. It is the same control panel the desktop app shows.

$ ssh -L 18790:127.0.0.1:18790 user@your-server

After installing

nocturn onboard asks for a model provider and key, optionally connects Telegram, and starts the gateway. Then try nocturn chat, read the documentation, or message your bot and approve the pairing code with nocturn pairing approve <code>.
