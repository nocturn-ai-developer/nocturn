Changelog

What changed, release by release

Installers for every version are on the GitHub release page. The npm package follows the same numbers.

0.2.1 November 3, 2026

  • Desktop app for Windows (.exe) and macOS (.dmg): the gateway in a window, with a tray icon that keeps it running when the window is closed.
  • Android client (.apk) and an installable web app, both connecting to a gateway you run elsewhere.
  • Control panel: chat with streaming and inline approvals, channels, schedules, memory, skills and settings in one page.
  • Semantic search over memories and the workspace: embeddings (Voyage, Ollama or built-in) fused with BM25. New search_workspace tool, nocturn search and nocturn index.
  • Voice notes from Telegram and audio files from Discord are transcribed before the agent reads them, by whisper.cpp or any OpenAI-compatible Whisper endpoint.
  • Approval risk: fixed rules for destructive calls plus a model trained on your own approve and deny answers, shown on every pending approval.
  • Terminal: a splash with the particle moon, a proper chat session, tool cards, boxed approvals, aligned status and doctor output.
  • Website: dark mode, documentation, download section, admin page for the token contract and X account, SEO and this changelog.
  • Opt-in NOCTURN_HOST and NOCTURN_TRUSTED_HOSTS for reaching the gateway from a phone over a private network.
  • CI builds all three installers on a version tag and publishes a GitHub release.

0.2.0 November 2, 2026

  • Miner with CPU auto-tune by temperature and memory, the pool server, and wallet linking by signature on Robinhood Chain.
  • Landing page with the scripted demo, the night timeline and the token section.
  • Gateway hardening: Host and Origin checks, private-address blocking for web tools, symlink-safe workspace paths.

0.1.0

  • First release: gateway, CLI, Telegram, Discord and Slack channels, approvals, cron schedules, memory and skills.
